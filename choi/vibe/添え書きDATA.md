# 添え書きDATA — DATA.md によるアプリ自己拡張の依頼

DATA.md をアプリ開発 AI に渡すときに添える文。以下の3文で足りる
(受け入れテスト 2026-08-17 で検証)。

---

あなたが作ったこのアプリを、DATA.md に従いサーバー教材読み込みに
対応させてください。

開発サーバーには BASIC 認証があり、AI は直接アクセスできません。必要な
API レスポンスやファイルは私が代理取得するので、curl コマンド等の形で
具体的に指示してください。

unit_id 指定なしの起動では従来どおり動くこと。既存動作の変更は不可。

---

## なぜこれだけでよいか(運用メモ)

- 実装方針・裁量・環境事実は DATA.md 側が既に扱っている(§3.4 型のみの
  宣言、§5 メディア別オリジン、§6 行動指針)。添え書きで繰り返さない
- 検証用の実データは、2文目のプロキシ宣言により AI が自分で指示して
  調達する(人間は事前準備不要。コマンドをコピペして結果を貼るだけ)
- 3文目は DATA.md §2 の「既存動作を保存してよい」(許可)を「不可」
  (要求)へ確定させるもので、依頼者にしか書けない唯一の固有情報
