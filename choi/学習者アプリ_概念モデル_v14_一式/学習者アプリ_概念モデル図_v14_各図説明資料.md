## 0. v14 の方針

v13で確立した **SSoT原則** を継続しつつ、**「習得」概念**と **階層的クリア伝搬構造**を概念モデルに反映。

UI上で観察される「カードに✓→デッキに✓→ユニット...上位まで連鎖」という流れを、概念モデルとして明確に表現する。

### 各図の主担当範囲

## 1. v14 の重要概念

### 1.1 「習得」とは

**カード単位の達成を表す用語**。

| 系統 | カード習得の条件 |
|---|---|
| 企画系・ニュース系 | カード成績クリア（会話問題のクリア） |
| 語彙系 | カード成績クリア＋単語成績クリア（すべての問題種別がクリア） |

UI上は「習得マーク（チェックマーク）」として表示される。

### 1.2 判定の基本ルール

**各問題種別は「直近2試行の正誤履歴」で判定する**：

| ステータス | 条件 |
|---|---|
| クリア | 直近2試行が両方正解 |
| 弱点 | 直近2試行が両方不正解 |
| 学習中 | それ以外（試行歴あり） |
| 未学習 | まだ試行していない |

実装上の具体的判定式は概念モデル外。

### 1.3 階層伝搬

```
カード習得（全カード）
　↓
デッキ成績.ステータス = 習得（全カードが習得）
　↓
パート成績.ステータス = 習得（全デッキが習得）
　↓
ユニット成績.ステータス = 習得（全パートが習得）
　↓
コース成績.ステータス = 習得（全ユニットが習得）
```

「全てクリア＝習得」の3値（未学習／学習中／習得）が、デッキ以上の階層共通のステータス値。

## B-1. 学習成果

### 目的
学習成果記録のエンティティ構成と関係性を示す。

### 含まれるエンティティ（v14で9つ＋参照5つ）

| エンティティ | 役割 |
|---|---|
| 単語問題セット | 語彙系のみ、3メソッド |
| 会話問題セット | 全カード共通 |
| カード成績 | 全カードに必ず1件 |
| 単語成績 | 語彙系のみ・0..1件 |
| **デッキ成績** | デッキ習得を管理 |
| **パート成績**（v14追加） | パート習得を管理 |
| **ユニット成績**（v14追加） | ユニット習得を管理 |
| **コース成績**（v14追加） | コース習得を管理 |
| 弱点補強リスト | 弱点判定カードを集約 |

参照：会員／コース／ユニット／パート／デッキ／カード／会話シーン

### 全階層に成績エンティティが対応する構造
v14ではカード成績〜コース成績まで7階層中6階層（カード〜コース）に成績エンティティが対応する。
カード以下（会話シーン・センテンス）には成績エンティティは置かない。

## C-1. コンテンツ階層詳細

### 目的
コンテンツの7階層構造とカード属性の主担当。

### 7階層
コース ＞ ユニット ＞ パート ＞ デッキ ＞ カード ＞ 会話シーン ＞ センテンス

### カード属性（V13踏襲）

| 属性 | 型 | 説明 |
|---|---|---|
| タイプ | enum { 語彙系, 企画系, ニュース系 } | デッキ.タイプから決定 |
| 単語種別集合 | Set ⊆ { 一般, タメ } | 語彙系のみ |
| タイトル / 画像 / 解説 | String | 全カード共通 |
| *単語 / *日本語意味 / *発音音声 | String | 系統別オプショナル |

V14での追記：コースnoteに「習得伝搬の最上位」の言及を追加。詳細はB-1/C-2参照。

## C-2. 系統別階層展開（V14で最大の更新）

### 目的
3系統の構造対比＋ **判定の基本ルール／カード習得／階層伝搬の主担当**。

### V14のブロック構成

| ブロック | 内容 |
|---|---|
| 企画系 | 通常1シーン、ガイドトーク系で2シーン |
| 語彙系 | 1単語=1カード、2シーン（一般・タメ） |
| ニュース系 | 1記事=1カード、2シーン（前半・後半連続） |
| **判定** | 直近2試行の正誤履歴で判定する基本ルール |
| **成績** | カード成績・単語成績の構造 |
| **習得** | カード習得の系統別条件と階層伝搬 |
| 凡例 | カード属性等の補足 |

### 判定の基本ルール（C-2主担当）

| ステータス | 条件 |
|---|---|
| クリア | 直近2試行が両方正解 |
| 弱点 | 直近2試行が両方不正解 |
| 学習中 | それ以外（試行歴あり） |
| 未学習 | まだ試行していない |

### カード習得の系統別条件（C-2主担当）

| 系統 | カード習得の条件 |
|---|---|
| 企画系・ニュース系 | カード成績クリア（会話問題のクリア） |
| 語彙系 | カード成績クリア＋単語成績クリア（すべての問題種別がクリア） |

**語彙系の場合のクリア対象**：
- 単語問題（単語成績で総合評価）：英日／日英／スペル
- 会話問題（カード成績で評価）：一般／タメ

各種別すべてを直近2試行両方正解（クリア）した状態がカード習得。

### 階層伝搬（C-2主担当）

```
カード習得（全カード）
　↓
デッキ成績.ステータス = 習得（全カードが習得）
　↓
パート成績.ステータス = 習得（全デッキが習得）
　↓
ユニット成績.ステータス = 習得（全パートが習得）
　↓
コース成績.ステータス = 習得（全ユニットが習得）
```
