## dd65fd6 — メディアパック仕様にTTSボイス解決と出力形式(デッキbody)を追加 (2026-06-04, Takahashi Hideki)

**変更規模**: 2 files, +196 / -4

### 主要テーマ
本コミットは大きく 3 つのテーマで構成される:

1. **概念モデルへの属性追加** — カードにタイトル、センテンスに話者を追加
2. **TTSボイスの解決ルール確定(§3.3)** — 話者からボイス・パラメータを解決する契約を新設
3. **出力形式(デッキbody)の確定(§9)** — 配信されるデッキオブジェクトの出力構造を新設

### 詳細

#### 1. 概念モデル図(属性追加)
- `カード` クラスに `タイトル` 属性を追加
- `センテンス` クラスに `話者` 属性を追加
- いずれも仕様書側の列⇄属性対応・出力形式の追加と整合させるための土台

#### 2. 列⇄モデル属性の紐付け(§1.2 / §1.3)
- 列5「チャプター名」を `デッキ.タイトル`(デッキ識別キー兼用)に変更
- 列6「シーン名」を `カード.タイトル`(カード識別キー兼用)に変更
- 列7「話者」を `センテンス.話者` に変更(従来は「表示用情報」)
- 列7はTTS自動生成モードではボイス解決キーを兼ねる旨を明記し §3.3 へ誘導

#### 3. TTSボイスの解決(§3.3 新設)
- 設定ファイル `teachingmaterial/config/chatterboxtts.csv` を参照する契約を定義(中身の管理は teachingmaterial 側、本仕様は参照契約のみ規定)
- CSVは UTF-8・BOM 除去前提、7列構成(話者 / voice / lang / exaggeration / cfg_weight / temperature / seed)
- 解決アルゴリズム: 話者がCSVと完全一致(大小区別)→ その行で生成 / 空欄・不一致 → カード内順番の偶奇でフォールバック(奇数=`alloy_female_cheerful_en`、偶数=`ash_male_cheerful_en`、`seed=12345`、他パラメータはエンジン既定)
- 偶奇はカードごとにリセット。日本語ロール名は全行フォールバックになり、特定行だけCSV登録名で上書き可能。文デッキにも同フォールバックを適用(単一ボイス既定化は残論点)

#### 4. 出力形式(デッキbody)(§9 新設)
- `body` は JSONをパースできる String 属性(ORM対象外)とし、`type` と `cards` から成ると定義
- `title` / `analysis` / デッキ画像 `image` は `body` 外のデッキオブジェクトプロパティとして保持(§9.3)
- `cards[]`(title / image / talks)・`talks[]`(person / en / ja1 / ja2 / audio)の表示構造を定義(§9.2)
- `analysis` はデッキ単位のブロブで `talks[]` と非1対1(解析器が1発話を複数文に分割しうる)
- メディアはファイル名格納+ §5.3 キー規約からパス導出(完全URLは焼き込まない)。全件生成完了後のみ配信のため空値は表現不要
- 入力⇄モデル⇄出力⇄出力先の対応表(§9.5)とスケルトン例(§9.6)を追加
- 旧§9「残論点 / 将来拡張」を §10 へ繰り下げ
