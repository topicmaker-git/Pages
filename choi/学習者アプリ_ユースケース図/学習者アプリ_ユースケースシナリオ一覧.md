## 7. U-7 配信・公開操作（v15 配信モデル対応で大きく更新）

### UC-N7.1 配信コンテナを即時配信する

| 項目 | 内容 |
|---|---|
| 主アクター | 投稿者 |
| 事前条件 | 配信対象（コース／ユニット／パート／デッキ）が公開状態。デッキの場合は表示フラグON。ユニット・コース・パートの場合は含まれる全デッキが公開＋表示ON |
| 基本フロー | ①配信設定画面（ギアアイコン > 配信設定） ②対象を選択（種別＋ID） ③「即時配信」を選択 ④「配信する」押下 ⑤配信コンテナが作成され、ステータス=配信済み |
| 関連UC | extend: 配信完了メッセージを受領する |
| 備考 | 対象種別：コース／ユニット／パート／デッキの4種類。タイムラインに混在する |

### UC-N7.2 配信コンテナを予約配信する

| 項目 | 内容 |
|---|---|
| 主アクター | 投稿者 |
| 事前条件 | UC-N7.1と同じ |
| 基本フロー | ①配信設定画面 ②対象選択 ③「予約配信」選択 ④日時指定 ⑤「配信する」押下 ⑥配信コンテナ作成（ステータス=予約中、配信予約日時セット） |
| 関連UC | extend: 配信完了メッセージを受領する（予約時刻に） |
| 備考 | 既存API仕様：過去1時間以内〜未来180日以内、1時間単位 |

### UC-N7.3 配信コンテナの配信を停止する

| 項目 | 内容 |
|---|---|
| 主アクター | 投稿者 |
| 事前条件 | 配信中または予約中の配信コンテナ |
| 基本フロー | ①配信設定画面 ②「配信停止する」押下 ③確認 ④停止 |
| 備考 | 学習者のタイムラインから当該配信が見えなくなる |

### UC-N7.4 デッキ単位の表示／非表示を切り替える

| 項目 | 内容 |
|---|---|
| 主アクター | 投稿者 |
| 基本フロー | ①配信設定画面または編集画面 ②「表示中／非表示」切替 ③保存 |
| 備考 | デッキ属性の変更。非表示状態のデッキは配信できない（ユニット配信時にも除外される） |

### 《システム自動》UC-N7.5 新規ユニット公開時の自動配信（v15対応）

| 項目 | 内容 |
|---|---|
| 主アクター | システム（受動UC） |
| 事前条件 | 新規ユニット公開 |
| 基本フロー | ①ユニット公開イベント発火 ②ユニットの対応プレイヤータイプを判定 ③種別に応じて配信コンテナを自動作成：<br/>　・ユニットタイプ → **ユニット配信コンテナを作成**（ターゲット種別=ユニット）<br/>　・デッキタイプ → **デッキ配信コンテナを作成**（ターゲット種別=デッキ、最初のデッキ） |
| 備考 | 既存ユニットの場合は自動配信されない（手動配信のみ）。タイムラインにはユニット配信とデッキ配信が混在する |
| 関連UC | extend: 配信完了メッセージを受領する |

### 《システム発火》UC-N7.6 配信完了メッセージを受領する

| 項目 | 内容 |
|---|---|
| 主アクター | 投稿者（受動UC） |
| 事前条件 | 配信イベント発生（手動／自動／予約） |
| 基本フロー | ①配信完了 ②投稿者にメッセージ表示（モーダル or トースト） |

## 9. v2 → v3 差分まとめ

| 章 | v2 | v3 |
|---|---|---|
| U-4 | 「全体デッキタイムライン」 | 「**グローバル**タイムライン」（v15用語） |
| U-4 | 「ユニット内デッキタイムライン」 | 「**ユニット**タイムライン」（v15用語） |
| U-4 | タイムライン内容 | ユニット配信・デッキ配信が**混在**する旨を明示 |
| U-7 | 「デッキを即時配信」 | 「**配信コンテナ**を即時配信」（4種別対象） |
| U-7 | 「デッキを予約配信」 | 「**配信コンテナ**を予約配信」 |
| U-7 | 「デッキの配信を停止」 | 「**配信コンテナ**の配信を停止」 |
| U-7 | 自動配信は「最初のデッキ」固定 | **コンテンツ種別に応じて切替**（ユニットタイプ→ユニット配信／デッキタイプ→デッキ配信） |
