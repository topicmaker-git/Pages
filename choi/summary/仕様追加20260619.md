# 【仕様更新のご連絡】管理画面(A系)コメント数・お気に入り数の表示／コメントのモデレーション

投稿システムの管理コンソール(A系)に、コメント・お気に入りまわりの仕様を追加・確定しました。学習者画面(B系)からのコメント投稿・閲覧に加え、**管理者・コンテンツ作成者がコメントを集約確認・モデレーション削除できる**ようになります。実装着手前にご確認ください。

参照: コミット `36ee8df` / `93f970f`、ワイヤーフレーム修正仕様 §12(`学習者アプリ_ワイヤーフレーム.pdf` に A-CMT を host 別 4 枚追加)、`choi/ちょい英語ミニブック投稿システム_ユースケース_画面一覧.md`(UC-45 / UC-46、A-CMT)

---

## 1. 対象画面

- **コース/ユニット詳細画面**: `A-MC2`(マイコース)/ `A-C2`(団体コース)/ `A-MU2`(マイユニット)/ `A-U2`(団体ユニット)
- **新設: コメント一覧画面 `A-CMT`**(上記 4 画面のヘッダから遷移する単一画面)

> 旧案の「各詳細画面内のコメントタブ」は**廃止**しました。コメント閲覧・モデレーションは独立画面 A-CMT に集約します。

---

## 2. コメント数・お気に入り数の表示(ヘッダの入口)

`A-MC2 / A-C2 / A-MU2 / A-U2` のヘッダに、以下 2 つの指標を表示します。

| 指標 | 集計 | 挙動 |
|---|---|---|
| **コメント数** | 配下を含めた**集約件数** | クリックで **A-CMT へ遷移** |
| **お気に入り数** | **配下レベル別**に表示 | **表示のみ**(遷移なし) |

- 各詳細画面自身が持つのは「入口」だけで、画面の主たる対応 UC は従来どおり変更なし。
- 集計の「配下」の範囲は host 文脈に従う(下記 §3 と同じ)。

---

## 3. コメント一覧 A-CMT(集約閲覧 = UC-45)

A-CMT は **「1 仕様 / 複数 host」方式**(`A-CM1` と同じ考え方)。**集約範囲と削除権限は遷移元(host)の文脈で決まります。**

**集約範囲(上位は配下を巻き取って表示):**

| host | 集約対象 |
|---|---|
| コース host(A-MC2 / A-C2) | コース対象 ＋ 配下ユニット・パート・デッキ対象のコメント |
| ユニット host(A-MU2 / A-U2) | ユニット対象 ＋ 配下パート・デッキ対象のコメント |

**実装上の要点:**
- **投稿先(保存)は各レベルのまま**。コメントは従来どおり `ターゲット種別 + ターゲットID`(コース/ユニット/パート/デッキの 4 種ポリモーフィック)で保存し、**データモデルは変更しません**。集約は**読み出し側で配下を巻き取るだけ**。
- 集約表示の各行には、**どの対象へのコメントかを示す種別ラベル＋リンク**を付与。
- 集約読み出しは**閲覧可能なターゲットのコメントのみ**にフィルタ。配下に外部公開ロックで格下げされたユニットや非公開デッキが混在しうるため、**visibility は動的評価**(お気に入り一覧 UC-42 と同一基準)を適用。

---

## 4. コメントのモデレーション削除(= UC-46)

**他者のコメントを削除できる主語と範囲:**

| 主語 | 削除できる範囲 |
|---|---|
| **コンテンツ作成者** | 自分が作成したターゲットに付いたコメント(コース主催者→コース対象、ユニット投稿者→ユニット及びその配下パート・デッキ対象。所有に紐づく) |
| **団体管理者** | 自団体メンバーが作成したコンテンツに付いたコメント(介入編集 UC-19 / UC-28 の延長＝上位権限) |

- A 系での操作面: **A-CMT の各行の削除が UC-46**(host が A-C2 / A-U2 なら団体管理者の介入編集、A-MC2 / A-MU2 なら作成者本人の文脈)。
- 削除は **物理削除**(`comment_t` を削除。投稿者本人削除 UC-44 と同じ挙動)。
- **誰が削除したか等の監査ログは本フェーズ対象外**(介入編集と同じく履歴は保持しない)。

> 参考: 投稿者本人による自分のコメント削除は **UC-44**(B 系/A 系いずれも)。UC-46 は「他者コメントの削除」=モデレーションです。

---

## 5. スコープ外 / 注意

- **学習者画面(B 系: B-02 / B-03 / B-05)上でのその場モデレーション削除は本フェーズの WF 対象外**。B 系はコメントの投稿・閲覧・本人削除(UC-43 / UC-44 / UC-45)を担当。
- コメント・お気に入りの対象は **コース / ユニット / パート / デッキの 4 種のみ**(カード・センテンス単位は対象外)。
- パートを持たないユニット(「ちょい英語ミニブック」等。デッキがブック直下に帰属)では、パート単位の入口は UI に現れない。
