### ✅ 保留P-17（パート階層の扱い）は確定済み（2026-06-10）

投稿システム側コミット **d9f0df6**（「メディアパック仕様: 教材階層のパート層を任意化」）で確定。**方針B（パートを任意のグルーピング層に）** を採用：

- **ユニット→デッキ：`1 : 1..*`**（デッキはユニット＝ブック直下に必ず帰属）
- **ユニット→パート：`1 : 0..*`**（パートは0個以上の任意グルーピング層）
- **パート→デッキ：`0..1 : 1..*`**（デッキは高々1つのパートに帰属。パート無し＝デッキがブック直下）
- ミニブックはパート未使用（デッキがブック直下、パート区切りビューなし）。単語型ブック等は複数パートを持ちうる
- **パートあり/なしはユニット単位で固定（1ユニット内で混在しない）**
- 「唯一の無名隠れパート」案は不要として却下

v15.3 で C-1（多重度・パート注記）／B-1（パート成績を任意化、ユニット成績は「パートを持つユニット＝全パート成績／持たないユニット＝全デッキ成績」を集約）／C-2（階層伝搬）に反映済み。詳細は §7.1.1 参照。

### ✅ UC-45 を不変条件ベースに再是正／コース公開伝播を v15.8 で反映（2026-06-30）

投稿システム コミット **cf52a04**（「『一般会員のみロック』下のコース構成不変条件を導入、UC-45を不変条件ベースに是正」）と **572c764**（「コース公開設定変更時の配下帰属ユニットへの上書き伝播（属性更新）を定義」）を反映。前者は **v15.7 で入れた UC-45「マスク行・viewer 依存」を撤回（再是正）** するもの。

**cf52a04（UC-45 の再是正・マスク行撤廃）**
- **『一般会員のみロック』下のコース構成の不変条件**を導入。外部から閲覧可能なコース内で「見える／見えない配下」の混在が生じる唯一の機構は `一般会員のみロック`（投稿者ロールで実効公開範囲が割れる。`全員ロック` は均一格下げで割れない）。これを**読み出し側（マスク行・viewer 依存）で吸収せず、混在の発生自体を入口で禁じる規則(制約)**を 1 本置く。
- 不変条件：`一般会員のみロック` 有効な団体では、**実効的に外部公開されるコース（管理者主催の公開／プライベート公開。一般会員主催は格下げで対象外）に一般会員投稿ユニットを含めてはならない**。
- **チェックは 1 つ・適用は 3 経路**（UC-02 ロック変更／UC-20 投稿・帰属／UC-12 コース公開化）で一様にリジェクト。
- **効果**：閲覧可能コースは常に all-or-nothing になり割れが構造的に消える → **UC-45 はマスク行・viewer 依存を撤廃**。host 到達者には配下の非公開除外コメントが全可読で、**行数=コメント数が一致**。価値メトリクス軸（非公開除外・閲覧者非依存）への統一は維持。お気に入り一覧 UC-42 の身元ゲート（`is_accessible:false`）は本不変条件の**対象外＝別機構**として据え置き。
- **P-16（visibility 評価）の適用箇所からコメント集約読み出しが外れる**。残るのは ①お気に入り一覧（UC-42）②遷移時フェイルセーフ の 2 つ。

**572c764（コース公開設定変更→配下帰属ユニットへの上書き伝播）**
- コース公開設定の変更（UC-12）時、配下の**コース帰属ユニット**の `Unit.公開` を新コース値で**上書き伝播（属性更新・DB 値を実体的に書換）**。目的は「ユニット単体の公開値=実効値」を保ち、読み出し時に親コースを辿らずユニット単体で判定完結させること。
- **非公開ユニットは不変**／公開・プライベート公開・団体限定公開は新コース値で上書き／**コース→非公開は全帰属ユニットを非公開へ（元値退避なし）**／**非公開→公開系の再公開は主催者の二択（全追従 or 全据え置き）**。
- コース非帰属（独立）ユニットは対象外。外部公開ロックは別層の規則（動的評価・DB 書換なし）として重なる。
- 影響は B-0 の コース note（公開伝播ルールを追記）・ユニット note（相互参照）と、UC 側の U-5（UC-12）／U-6（UC-20）／U-4（UC-45 のマスク行撤廃）。**データモデル構造・派生属性の集合・UC・アクター構造は不変**。

## 5. v15時点の確定事項

### 3.1 階層構造（7階層、v10から維持）

```
コース ＞ ユニット ＞ パート ＞ デッキ ＞ カード ＞ 会話シーン ＞ センテンス
```

### 3.2 多重度

| 親→子 | 多重度 | 備考 |
| --- | --- | --- |
| コース→ユニット | 1 : 0..* | コース帰属任意 |
| ユニット→デッキ | 1 : 1..* | **デッキはユニット直下に必ず帰属**（v15.3） |
| ユニット→パート | 1 : 0..* | **パートは任意のグルーピング層**（v15.3） |
| パート→デッキ | 0..1 : 1..* | **デッキは高々1パートに帰属**（v15.3・投稿システム d9f0df6） |
| デッキ→カード | 1 : 1..* | |
| カード→会話シーン | 1 : 1..N | 系統依存（C-2参照） |
| 会話シーン→センテンス | 1 : 4..* | 標準4（話者2人×2ターン） |

### 3.3 カード属性（v13から維持）

| 属性 | 型 | 説明 |
| --- | --- | --- |
| タイプ | enum { 語彙系, 企画系, ニュース系 } | デッキ.タイプから決まる |
| 単語種別集合 | Set ⊆ { 一般, タメ } | タイプ=語彙系のときのみ |

### 3.4 学習成果記録（v14踏襲）

**カード成績**（全カードに1件必ず存在）
- ステータス：未学習 / 学習中 / クリア / 弱点（4値）

**単語成績**（語彙系カードのみ・0..1件）
- ステータス：未学習 / 学習中 / クリア / 弱点（4値）

**デッキ成績／パート成績／ユニット成績／コース成績**
- ステータス：未学習 / 学習中 / 習得（3値）
- 階層的に伝搬

### 3.5 判定の基本ルール（v14踏襲・C-2主担当）

各問題種別の判定は **直近2試行の正誤履歴** で行う：

| ステータス | 条件 |
|---|---|
| クリア | 直近2試行が両方正解 |
| 弱点 | 直近2試行が両方不正解 |
| 学習中 | それ以外（試行歴あり） |
| 未学習 | まだ試行していない |

### 3.6 カード習得と階層伝搬（v14踏襲・C-2主担当）

| 系統 | カード習得の条件 |
|---|---|
| 企画系・ニュース系 | カード成績クリア |
| 語彙系 | カード成績クリア＋単語成績クリア |

階層伝搬（v15.3：パート任意化を反映。パートあり/なしはユニット単位で固定＝混在なし）：
```
カード習得（全カード）
　↓
デッキ成績 = 習得（全カードが習得）
　↓
【パートを持つユニット】 パート成績 = 習得（パート内全デッキ）→ ユニット成績 = 習得（全パート）
【パートを持たないユニット（例：ミニブック）】 デッキ成績 → ユニット成績 = 習得（全デッキ）
　↓
コース成績 = 習得（全ユニットが習得）
```
※ 1ユニット内でパート所属デッキとユニット直下デッキが混在することはない（ユニット単位でどちらかに固定）。パートを持たないユニットにはパート成績は存在しない。

### 3.7 配信の構造（v15更新）

**配信コンテナ**
- ターゲット種別 + ターゲットIDで配信対象を表現（ポリモーフィック）
- 4種類のターゲット種別をサポート（コース／ユニット／パート／デッキ）
- 種別：即時／予約
- ステータス：予約中／配信済み

**プレイヤー（v15追加）**
- タイプ：ユニットタイプ／デッキタイプ
- 配信コンテナのターゲット種別と原則対応
- 将来増加可能性あり

**タイムライン**
- 3種類の絞り込みパターン（グローバル／お気に入り／ユニット）

**公開・配信・表示の3軸独立**（B-2主担当）
- 公開状態（デッキ属性、3値enum）
- 表示フラグ（デッキ属性、boolean）

### 7.1.1 保留P-17の詳細（パート階層の扱い）

**✅ 確定結論（2026-06-10・投稿システム コミット d9f0df6）**：
**方針B（パートを任意のグルーピング層とする）** を採用。最終的な多重度は次のとおり：

```
コース  "1"   *-- "0..*" ユニット    (コース帰属任意)
ユニット "1"   *-- "1..*" デッキ      (デッキはユニット＝ブック直下に必ず帰属)
ユニット "1"   *-- "0..*" パート      (パートは任意のグルーピング層)
パート  "0..1" o-- "1..*" デッキ      (デッキは高々1パートに帰属)
```

- ミニブックはパート未使用（デッキがブック直下、デッキ区切りビューなし）。単語型ブック等は複数パートを持ちうる
- 議事録の途中で挙がった「唯一の無名隠れパート」案は不要として却下（高橋さん・佐藤さん合意）
