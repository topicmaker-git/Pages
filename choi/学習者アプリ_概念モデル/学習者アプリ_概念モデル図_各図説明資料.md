## 1. v15 で更新された概念

### 1.1 配信コンテナ（旧称「配信」）

配信は **ターゲット種別 + ターゲットID** で配信対象を表現する **ポリモーフィック構造** に変更。
v14までは「デッキを配信する」のみだったが、v15では4種類のターゲットに対応：

| ターゲット種別 | 用途例 |
|---|---|
| コース | コース全体を配信（将来用） |
| **ユニット** | **ユニット単位（旧称ミニブック）配信。例：「英語を英語で学ぶ」** |
| パート | パート単位で配信（将来用） |
| **デッキ** | **単一デッキの配信。例：インバウンドコンテンツ** |

コンテンツの性質に応じて適切なターゲット種別で配信する。

### 1.2 プレイヤー（v15追加）

学習者が学習を進める際の **UI再生コンポーネント** の種別を表すエンティティ。

| プレイヤータイプ | 説明 |
|---|---|
| ユニットタイプ | ユニット単位のまとまった学習体験を提供（複数デッキを連続再生・前後半に分割等） |
| デッキタイプ | 単一デッキの学習体験を提供 |

配信コンテナのターゲット種別と原則対応する。将来増加可能性あり。

### 1.3 用語統一：「ミニブック」→「ユニット」

議事録で「ミニブック」「ユニット」「チャプター」が混在していたため、v15では **「ユニット」に統一**。
旧称ミニブックは概念モデル上では「ユニット」と呼ぶ。

## B-0. 既存エンティティ差分（v15.7 で更新）

V15に対して以下を追加：
- **コース** に `公開（4値enum）` と `投稿者制限（2値）` を参照属性として追記（投稿システム側で定義済みの属性。閲覧権限判定のため）
- **ユニット** に `公開（4値enum）` を参照属性として追記
- 各noteで投稿システム側との関係を明記

**v15.4 追加（お気に入り・コメント仕様Q&A 2026-06-19 反映）**：
- **お気に入り**：削除連鎖（パート・デッキ単体削除でも連鎖）／一覧の閲覧可否評価（アクセス不可は `public_id` を返さず `target:null`+`is_accessible:false` で全件返す＝漏洩経路にしない）／登録数の2本立て（直接数・集約数）
- コース・ユニット・デッキに **派生属性 `お気に入り直接数`**、コース・ユニットに **`お気に入り集約数`（配下含む延べ・非公開除外）** を追加。集約範囲は visibility 評価とは別軸
- **コメント**：削除連鎖／**階層集約表示**（保存はモデル不変・読み出し側で上位が配下を巻き取る・閲覧可能ターゲットのみ）／削除権限は投稿者本人＋モデレーション（作成者・団体管理者＝UC-46）
- 基調は「データモデル構造は変えず、確定挙動を注記＋派生属性で記録」。UC-44/45/46・削除連鎖規則の更新はユースケース側（別ストリーム）

**v15.5 追加（A系コメント数表示・モデレーション仕様 2026-06-19 反映）**：
- **コメント集約件数（派生）** をコース・ユニットに追加。コース/ユニット詳細ヘッダに配下を含めた集約件数を表示し、押下で集約コメント一覧（A系は独立画面 A-CMT）へ遷移
- **軸違いに注意**：お気に入り集約数＝非公開除外・閲覧者非依存（静的）／コメント集約件数＝visibility 動的評価・閲覧者依存（UC-42/45 と同基準）
- 旧「各詳細画面内のコメントタブ」廃止→A-CMT に集約。集約範囲・削除権限は host 文脈で決定。これらは UC/WF 側仕様で B-0 には参照注記のみ
- 招待フロー・会員管理・WF51枚など A系管理コンソール全般は投稿システム/UC/WFの別ストリームで、学習者アプリ概念モデルの対象外

**v15.6 追加（プライベート公開=unlisted 再定義 2026-06-23・投稿システム e9f5853 反映）**：
- プライベート公開を **unlisted（発見の抑制）** として再定義。公開メニュー・一覧・検索に露出しないだけで、参照（リンク・お気に入り等）を持つ会員はアクセス可。コース note の公開enum定義を更新（enum 値自体は不変）
- お気に入り一覧の出し分け（`public_id` 抑制・`is_accessible:false`）を、**身元ゲート（非公開・団体限定公開・外部公開ロック格下げ）で本人が閲覧資格を失った場合のみ**に限定。公開→プライベート公開(unlisted) は放置でよい（本人専用一覧＝unlisted 抑制の対象外、参照保持者はアクセス可）
- 旧 Q1「public→private公開でアクセスさせない・public_id 漏洩防止」は本ケースで撤回。データモデル構造・派生属性は不変

**v15.7 追加（コメント/お気に入り数の意味論統一 2026-06-29・投稿システム 13d436d 反映）**：
- **コメント数＝お気に入り数を同一の価値メトリクス軸（非公開除外・閲覧者非依存）に統一**。コース/ユニットの `コメント集約件数` 属性ラベルを「visibility動的・閲覧者依存」→「非公開除外・閲覧者非依存」に是正。**v15.5 の「軸違い」は撤回**（上記 v15.5 追加の記述は本ブロックで上書き）
- **コメント集約読み出し（UC-45）をマスク行方式に是正**：「閲覧可能ターゲットのみフィルタ除外」→「アクセス不可は本文・投稿者をマスクして行は残す／非公開配下のみ行ごと除外／行数=コメント数」。ビューア依存は本文可読性のみ＝行集合・件数は閲覧者非依存
- A系 A-CMT（作成者/管理者のモデレーション画面）は自スコープ内を非公開配下も含め全件・マスクなしで表示するため価値メトリクス数と不一致でよい（学習者側集約一覧とは別物・A系/対象外・参照注記のみ）。データモデル構造・派生属性の集合は不変

**設計方針**：
- 団体エンティティ自体は学習者アプリには持たず、投稿システム側のものを参照する
- デッキの公開状態（3値enum）は学習者アプリ独自属性として残す（v12からの経緯）
- デッキ.タイプ（word/talk/news）と投稿システム側「会話/文」は別軸の概念

**注意**：「公開・配信・表示の3軸独立性」の説明はB-2に集約。詳細用語対応は引き継ぎ資料 §7 参照。

## B-1. 学習成果

V14踏襲ベース。v15.3で **パート任意化（保留P-17確定）に追従**：

- パート成績はパートが存在する場合のみ生成（会員×パートで0..1件）。パートを持たないユニット（例：ミニブック）には存在しない
- パートあり/なしはユニット単位で固定（1ユニット内で混在しない）。ユニット成績は、パートを持つユニットは全パート成績を、持たないユニットは全デッキ成績を集約して判定
- 詳細は引き継ぎ資料 §7.1.1 参照

## B-2. タイムライン（V15で大きく更新）

### 含まれるエンティティ（v15で2→3つに）

| エンティティ | 役割 |
|---|---|
| **配信コンテナ**（v15で改名） | デッキ・ユニット等を実際にタイムラインへ載せる行為 |
| **プレイヤー**（v15追加） | 学習者が学習を進める際のUI再生コンポーネント |
| タイムライン | 配信コンテナを集約表示するビュー |

参照エンティティ：会員／コース／ユニット／パート／デッキ

### v15での配信コンテナの構造

```
配信コンテナ {
    +enum ターゲット種別 : コース / ユニット / パート / デッキ
    +String ターゲットID
    +enum 種別 : 即時 / 予約
    +enum ステータス : 予約中 / 配信済み
    +Date 配信予約日時
    +Date 配信日時
}
```

ターゲット種別＋IDの組み合わせで配信対象を保持する **ポリモーフィック構造**。お気に入り・コメントと同じパターン。

### プレイヤーの構造

```
プレイヤー {
    +enum タイプ : ユニットタイプ / デッキタイプ
}
```

本概念モデルではプレイヤーの挙動詳細は記述しない。UI設計フェーズで詳細化する。

### 公開・配信・表示の3軸独立（v14踏襲・B-2主担当）

| 概念 | 所在 | 型 |
|---|---|---|
| 公開状態 | デッキ属性 | 3値enum（公開／プライベート／非公開） |
| 表示フラグ | デッキ属性 | boolean（ON/OFF） |
| 配信コンテナ | 独立エンティティ | - |

### デッキを配信できる前提条件
1. 所属コースが公開状態
2. デッキの公開状態が「公開」
3. デッキの表示フラグがON

ユニット等の他のターゲット種別での配信は、含まれる全デッキが上記条件を満たすことが前提。

### タイムラインの3種別

| 種別 | 内容 | 表示場所 |
|---|---|---|
| グローバル | すべての配信コンテナを集約 | ホーム「発見」タブ |
| お気に入り | 会員がお気に入りしたコンテンツの配信のみ | お気に入りタブ |
| ユニット | 1ユニットに紐づく配信のみ | ユニットページ |

## C-1. コンテンツ階層詳細（v15.3 で更新）

v15.3で **パート層を任意化**（保留P-17確定・投稿システム d9f0df6 追従）：

- ユニット→デッキ `1 : 1..*`（デッキはユニット＝ブック直下に必ず帰属）
- ユニット→パート `1 : 0..*`（パートは任意のグルーピング層）
- パート→デッキ `0..1 : 1..*`（デッキは高々1パートに帰属。アグリゲーション `o--` で表現）
- ミニブックはパート未使用（デッキがブック直下）。単語型ブック等は複数パートを持ちうる
- パートクラスに任意グルーピング層であることを示す note を追加

v15.2で **センテンスクラスに `+String 話者` 属性を追加**（V14踏襲ベース）。

- 話者属性は会話シーン内の発話者を示す表示用文字列（例：「案内係」「スタッフ」「Mike」等）
- UI上で話者を区別して表示するために用いる
- 投稿システム側 dd65fd6（2026-06-04）でセンテンスに正式に属性化されたため追従

カード.タイトル属性は v11 以降学習者アプリ側にも存在しており、dd65fd6 で投稿システム側にも追加された結果、整合済みとなっている。
